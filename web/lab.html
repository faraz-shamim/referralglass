ReferralGlassA SMALL, REPRODUCIBLE CHECK

Show the model’s work.

This lab compares local MiniLM semantic retrieval with a TF-IDF cosine baseline on 24 fixed, synthetic document-type cases. Each case contains one target passage and five passages of other document types. The same text and requirements are used for both methods.

It measures top-1 retrieval on this small fixture, not clinical accuracy, real-world completeness, or time saved by a clinic. The corpus is bundled with the source so the examples, labels, and failures can be inspected.

First run downloads about 50 MB of generic model and runtime assets. No patient data is used.
